# SM Associates – AI Project Knowledge Base

## Project Overview

This repository contains the official source code for the SM Associates Risk Management Pvt. Ltd. corporate website.

The website is developed using:

* React
* Vite
* TypeScript
* Tailwind CSS
* Framer Motion

This project follows the DPOS (Digital Presence Operating System) methodology.

---

# Project Objective

Build a premium enterprise website that establishes SM Associates as a trusted Recovery and Risk Management partner for Banks, NBFCs, Housing Finance Companies, Fintech Lenders, and Financial Institutions.

Primary objectives:

* Build trust.
* Demonstrate operational expertise.
* Showcase enterprise capabilities.
* Generate qualified business enquiries.
* Maintain long-term scalability.
